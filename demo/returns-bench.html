Example numbers

Each stage on the dashboard uses the same name as the status on the job, so nobody has to translate between screens.

Point the camera at the label and Returns Bench looks for a hash, "job number" or "order number". If the label is torn or the light is bad, press the mic and read the number instead.

No more camera rolls full of unlabelled boxes. Open any job, from any day, and its photos are right there, in the order they were taken.

The email goes from your returns address to the contact each tenant set up, with the job number or a description in the subject. The tenant replies with a decision and you log it on the job.

Month-end reporting in a few taps. Search any return by date, tenant or order number, and hand tenants a clean record of every job you handled for them.

Upload your logo and a CSV of SKUs, and set up each tenant's email. Every warehouse runs its own separate copy, so your data never mixes with anyone else's. Light and dark mode included.
