# Updating this library

This repository is maintained by Lillian for incremental private work.

1. Add one file in `patterns/` using the next unused two-digit number.
2. Use a durable kebab-case filename: `09-cursor-driven-hero.md` is reserved as a likely future direction, not a commitment.
3. Include Chinese and English names, an effect description, and one copy-ready English prompt.
4. Check that the prompt covers relevant input modes, accessibility, reduced motion, cancellation/boundaries, state handling, and implementation safeguards.
5. Update `patterns/README.md` and `CHANGELOG.md` in the same change.
6. Keep commits small and descriptive; do not add private client, employer, health, account, or analytics data.

## Quality check

Before committing, confirm that the pattern describes a reusable interaction rather than a portfolio-specific screen, and that it does not promise a production-ready implementation unless one actually exists.
